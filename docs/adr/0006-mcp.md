# 0006 · Tools are defined with the Model Context Protocol (MCP)

**Status:** Accepted · **Date:** 2026-10-03

## Context
Skills use tools (literature search, sandbox, Lean, GPU). It must be easy for the community to add new tools, and the existing ecosystem should be reused.

## Decision
External tools are defined as MCP servers (`protocol: mcp`, `server: ...` in `skills/*.yaml`). Internal operations (such as `graph.read`, `budget.read`) stay `builtin`. Permission checks happen above the MCP layer, in the orchestrator: an MCP server cannot grant authority on its own. In Phase 5, QuaeraLabs itself is also opened to other agents as an MCP server.

## Consequences
- The first MCP servers in Phase 1: `literature`, `sandbox`, `lean`. `compute` in Phase 2.
- Third-party MCP servers ask for user approval on first use.
