# Weekly feedback interview (20 min)

The goal is not to defend the product but to learn what the participant actually did. Ask about concrete events from the last week instead of hypothetical questions.

## Flow
1. **(2 min) Consent:** "Do you mind if I record my notes?" Recording happens only with explicit consent.
2. **(6 min) Last week:** "When did you last open QuaeraLabs this week? What for?" If they never opened it: "Was there a moment when you thought about opening it but didn't? Why not?"
3. **(6 min) Open a research run together:** open the latest project on the participant's screen.
   - "Did you trust the result? Based on what?"
   - "Did anything an agent did surprise you, in a good or bad way?"
   - "What did you base your decisions on in the approval cards? Was information missing?"
4. **(4 min) Failures:** "Did anything happen that you think was wrong?" If so, create a case together with **Report a problem** and write the expected behavior in the participant's own words.
5. **(2 min) Reuse:** "Will you use this for your own work next week? For which question?" (Gate criterion: [metrics](metrics.md))
